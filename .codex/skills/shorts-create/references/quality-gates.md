# Creation quality gates

Before a render is publishable, verify:

- 9:16 output at configured resolution, frame rate, and duration;
- readable text within platform-safe areas and no clipped glyphs;
- correct app name, icon, screenshots, claims, calculations, and CTA;
- no secrets, personal data, test ads, debug overlays, or unlicensed assets;
- audio presence and loudness when required; label silent exports;
- representative hook, middle, and CTA frames by visual inspection;
- metadata follows the channel's actual navigation behavior.

A renderer exit code alone is not visual QA.
