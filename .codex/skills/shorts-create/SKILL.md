# Shorts Create

Create a video plan with one clear viewer promise and a traceable source for every product claim.

- Product introduction: problem → differentiator → product proof/demo → CTA.
- Repeatable quiz: hook → prompt → thinking time → answer/explanation → CTA.
- Repeatable utility series: recurring user situation → one workflow → result → CTA.

Read [references/quality-gates.md](references/quality-gates.md) before rendering a new recipe or materially changing a template.

Use the repository CLI to validate and render. Preserve the plan, recipe version, seed, asset references, output, and QA result. Validate factual accuracy independently from visual rendering.

Do not publish from this skill. Hand off only a QA-passed render and proposed metadata. If assets are missing, produce the plan and an exact asset request rather than substituting unrelated media.
