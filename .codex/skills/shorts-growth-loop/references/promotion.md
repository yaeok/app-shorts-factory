# Learning promotion

A promotion proposal includes:

- learning ID and state;
- affected recipe and proposed next version;
- supporting experiments and comparable checkpoints;
- observed improvement and KPI relevance;
- counterexamples and applicability boundary;
- exact change, migration impact, and rollback;
- tests and preview evidence;
- approver and approval timestamp.

Retire a learning when later evidence contradicts it. Link the replacement instead of erasing history.
