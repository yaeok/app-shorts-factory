# Shorts Growth Loop

Create durable growth without autonomous sprawl. A learning moves through `candidate → replicated → approved → adopted → retired`. Read [references/promotion.md](references/promotion.md) before promoting a learning or creating another campaign from a template.

## Safe self-improvement

- Derive candidates only from recorded plans, publications, and measured checkpoints.
- State evidence, applicable context, counterexamples, and confidence.
- Require replication or a documented exceptional downstream result before approval.
- Promotion creates a new recipe version; it never rewrites historical artifacts.
- Validate the new version with tests and a preview before adoption.

## Safe replication

- “Self-replication” means instantiating the versioned workflow for another user-approved app or channel.
- Never create channels, credentials, accounts, schedules, or public posts without authority.
- New campaigns start in draft/dry-run mode and inherit no secrets.
- Keep per-app brand, claims, assets, destinations, ledgers, and metrics isolated.
