# Metric model

Every value has a state: `measured`, `calculated`, `estimated`, `unavailable`, or `pending`.

Recommended checkpoints are 24 hours, 72 hours, and 7 days. Store observation time and source because totals change.

Use the nearest observable funnel:

`views → retained views → engagement → profile visits → link clicks → store views → first-time downloads`

Do not imply per-video download attribution when multiple publications share one destination without campaign-level measurement.
