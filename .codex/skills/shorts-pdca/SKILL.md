# Shorts PDCA

Use publication records and checkpoint snapshots to produce one integrated review: hypothesis, change, fixed conditions, measured result, uncertainty, decision, and next test. Read [references/metrics.md](references/metrics.md) when defining a KPI model or comparing channels.

- Prioritize the configured conversion KPI; use views, retention, engagement, profile visits, and clicks as diagnostics.
- Never convert missing, delayed, private, or threshold-suppressed values to zero.
- Compare like-for-like windows and identify confounders.
- Avoid declaring a winner from one post. Mark a learning provisional until replicated or supported by a strong downstream outcome.
- Change one declared variable next unless the current format is invalid or unsafe.
- Preserve losing results so failed tests are not repeated.

Output a machine-readable review plus a short human summary.
