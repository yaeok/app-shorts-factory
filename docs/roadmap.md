# Roadmap

## M1: Workflow foundation — complete

- Per-app workspaces and repeatable recipe contracts
- Product-introduction and deterministic quiz examples
- Six Codex skills for intake, creation, YouTube publication, PDCA, and learning promotion
- Static images and screen recordings in the renderer
- Portable validation and tests

## M2: Planner and generator plugins

- Implemented brief and guided interview, deterministic product and quiz plans, proof-only app copy, and retained asset snapshots
- Plugin interface for number sequences, calculations, quizzes, tips, and app workflows
- Domain-specific independent answer and claim validators
- BGM, narration, captions, and multiple visual templates

## M3: YouTube adapter

- Implemented desktop OAuth, recorded approval per upload, local simulation, upload ledger, verification, and uncertain-result reconciliation
- Validate credentialed private upload on an owner-approved test channel
- Add a bounded standing approval mode after testing per-video approval in production

## M4: Metrics and PDCA

- Implemented YouTube Data API counters at 24h, 72h and 7d, imported metrics, recorded comparisons, and optional AI proposals
- Add automated retention and campaign attribution connectors

## M5: Scheduling and learning promotion

- Implemented timestamped queue and scheduled runner command, promotion after comparable repeated results and media approval, and draft-only campaign transfer
- Add a hosted runner with durable storage and an operator view for managing the queue

No milestone grants permission to create accounts, channels, credentials, public schedules, or posts without explicit authorization.
